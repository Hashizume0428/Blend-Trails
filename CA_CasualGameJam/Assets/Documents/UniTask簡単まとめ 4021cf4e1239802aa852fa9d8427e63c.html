UniTask簡単まとめ

UniTask

Unityで非同期処理を簡単に実装するためのライブラリ。

using Cysharp.Threading.Tasks;

基本的な使い方

private async UniTask AttackAsync()
{
    Debug.Log("開始");
    await UniTask.Delay(1000); // 1秒待機
    Debug.Log("終了");
}
  • async：非同期メソッドを宣言
  • await：処理の完了を待つ（ゲーム全体は停止しない）
  • .Forget()：完了を待たずに実行

UniTaskとUniTaskVoid

UniTaskUniTaskVoid
await で完了を待てる完了を待てない
.Forget() で待たずに実行も可能待機不要なイベント処理向け

基本的には UniTask を使用する。

await AttackAsync();   // 完了を待つ
AttackAsync().Forget(); // 完了を待たない

よく使うメソッド

メソッド内容
UniTask.Delay(1000)1秒待機
UniTask.Yield()後続のPlayerLoopで再開
UniTask.WaitUntil(() => isReady)条件成立まで待機
UniTask.WhenAll(A(), B())両方の処理が完了するまで待機

※ WhenAll は並行処理であり、必ずしもマルチスレッドではない。
