① 点を追加する

usingUnityEngine;publicclassLineController :MonoBehaviour
{
    [SerializeField]privateLineRendererlineRenderer;publicvoidAddPoint(Vector3position)
    {// 点の数を1つ増やすlineRenderer.positionCount++;// 最後の点に座標を設定lineRenderer.SetPosition(lineRenderer.positionCount-1,position
        );
    }
}

例えば、次のように呼び出します。

AddPoint(newVector3(0,0,0));AddPoint(newVector3(1,1,0));AddPoint(newVector3(2,0,0));

これで3つの点が順番につながり、折れ線が描画されます。

ポイント：

  • positionCount++で点を追加
  • SetPosition()で追加した点の位置を設定
  • 点と点の間は自動的に線で結ばれる

  • 点が０個の場合は何も表示されない
