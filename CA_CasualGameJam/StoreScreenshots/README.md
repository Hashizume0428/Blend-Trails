# ストア掲載用スクリーンショット 20枚

各PNGは1080×1920 px、RGB、不透明、8MB未満です。実際のゲーム画面を指定解像度で直接描画して撮影しています。

このフォルダー直下の `01_` から `20_` までのPNG20枚がストア掲載用です。

- `01`: タイトル
- `02`: Stage 1の操作ガイド
- `03`〜`17`: 盤面・配色・描画経路の異なる開始画面とプレイ途中
- `18`: Stage 3のクリア演出
- `19`〜`20`: Stage 8・13のクリア結果

`preview.jpg` は20枚の一覧確認用です。ストア掲載用PNGと寸法が異なります。

プロジェクト直下の `StoreScreenshots.zip` にも掲載用PNG20枚だけをまとめています。

撮影・検証の補助ファイルは `output/store-screenshots-tools/` にあります。ゲームのソースやシーンは変更せず、撮影前のEditor設定と保存済み進行データを復元しています。
