# スマホ縦画面の表示修正

添付画像では、横長のゲーム表示領域がスマートフォンの縦画面の中央に縮小され、上下に黒い余白が出ている。
ゲーム内のタイトルとステージUIはすでに縦画面に対応している。

## 修正

- 共通のWebGL初期サイズを960×600から540×960へ変更。
- 現在有効な `unityroom` ビルドプロファイルの上書き設定も540×960へ変更。
- UIレイアウトやゲームロジックの変更はなし。

## 確認

- UnityのGameビューを540×960にしてタイトルを再生。
- フレームが進み、開始ボタンが有効になることを確認。
- `title-540x960.png` に黒い余白のないタイトルを保存。
- 検証後、元のSampleSceneとGameビューの選択へ復元。
- WebGLビルド成功（警告0件・エラー0件）。出力先は `Build/WebGLPortrait/`。

## unityroomへ反映

1. ゲーム管理画面の「WebGL設定」で表示サイズを **幅540、高さ960** に変更する。
2. 再ビルドした `Build/WebGLPortrait/Build/` のデータ・framework・wasmファイルを「WebGLアップロード」から差し替える。
3. スマートフォンでゲームを再読み込みし、タイトルとステージの表示を確認する。

unityroomの表示サイズはサイト側にも保存されるため、Unityの初期サイズの変更だけでは公開済みゲームの横長表示が残る可能性がある。
公開済みサイトの設定変更・アップロードと、スマートフォン実機での確認は未実施。
