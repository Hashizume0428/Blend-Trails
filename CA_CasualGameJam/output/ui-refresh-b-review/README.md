## 直近の仕様を反映する点

- タイトルは現在のステージへ直接進むボタン1つ。画像内のSTAGE 3は例示。
- クリア後はHOMEを表示せず、中央の次ステージボタン1つ。Stage3の次はSTAGE 4。
- クリアではプレイ用HUDを隠す。以前のB案クリア画像にあった大きなモーダル、HOME、クリア説明文は使わない。
- 完成盤面の縦横比・線・着色を維持したまま、プレイ時の60%へ縮小する。最終PNGは初稿の縮小比率を調整している。
- 指ガイドはStage1だけ。赤・青のどちらから操作しても既存の状態判定に従って案内を更新する。PNGは赤の案内例。
- 不正解は両色の線を確定した時に判定。誤りマスだけ2秒間点滅し、線と内部の構成色を保持する。不正解SEと強い端末振動は各1回。
- 色選択は両方の線の終点が同じマスにある時。選択後、同じ終点から改めてドラッグして続行する。通常の単独終点は直接再開できる。
- 5ステージごとの色ローテーションは既存仕様を継承する。Stage1〜5：赤＋青＝紫、Stage6〜10：赤＋黄＝オレンジ、Stage11〜15：青＋黄＝緑。以降15ステージ周期。
- 色の切り替えは開始点、指定枠、禁止色、混色早見表、線、タイル、色別リセット、色選択へ共通適用する。

## 画像の読み方と確認事項

各PNGは見た目の認識を合わせるための静止画です。指の移動、点滅、縮小、紙吹雪、音、端末振動の動作はこの資料では検証できません。細部の色や縮小寸法は実装時に数値を指定します。

確認したいのは、B案の印象、盤面とボタンの大きさ・余白、ガイドと色選択の見やすさ、クリア時の構成です。修正は画面番号と対象箇所で指定できます。

画像は未承認の提案です。今回の資料を決定済みデザインとして自動的に記録しません。
