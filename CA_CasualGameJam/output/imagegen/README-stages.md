- 画像一覧: stages-index.html をブラウザーで開いてください。
- AIへの入力: stage-01-clean.png ～ stage-10-clean.png を利用してください。
- 生成方式: 内蔵 image_gen による画像編集。ステージ1は前回の清書を再利用しています。

- ステージ3中央の紫枠は、元画像に合わせて縦2マスを囲む長方形です。
