# B案UI 実装・検証結果

実装・確認：2026-10-25（Asia/Tokyo）、Unity 6000.3.24f1。

[実装画面一覧](index.html) ／ [主要6画面のPNG](overview.png) ／ [縦長画面](stage11-tall.png)

## 実装した内容

- 指定されたタイトル画像を `Assets/UI/ToonBold/ApprovedTitle.png` として保存。添付原本とSHA-256が一致することを確認した。
- タイトルのロゴ・混色モチーフは赤＋黄＝オレンジで固定。元画像のSTAGE 6ボタン部分は使わず、進行番号に連動するボタン・文字・タップ判定を別に配置した。
- タイトルと全30ステージを、青空・雲・クリーム色・濃紺の太い枠・丸い文字に統一した。
- 3配色の開始点・指定色枠・タイル面・線・混色ガイド・リセット・色選択を連動させた。黄色の操作アイコンと文字は濃紺で表示する。
- Stage1の指と点線、誤りマスの2秒間の点滅、線の再開、色選択カードを保持してB案へ反映した。
- クリア後はパレットに合わせた紙吹雪、完成盤面の60%縮小、中央の次ステージボタン1つ。プレイ用HUDとHOMEは非表示。
- 盤面の問題データ、クリア条件、進行保存、線の操作、不正解SE・振動処理は既存の仕組みを維持した。
