# タイトルロゴの登場 修正

初回読み込み中に登場アニメーションが進み、最初の表示で既にロゴが出終わる問題を修正しました。再現テストでは修正前の初回表示が1.6秒まで進んでいました。

最初の描画を初期状態で保持し、表示するフレームに合わせて演出を進めます。起動時の長いフレームでも登場が飛ばされないよう、登場中に進める時間を制限しています。

修正後のタイトル専用テスト5件通過。1.1秒の読み込み遅延を入れた実際のタイトルシーン再ロードから録画し、非表示→拡大しながら登場→着地を確認しました。
