# Blend Trails: Color Puzzle — UI改善

2026-10-25（Asia/Tokyo）

## 変更内容

- 青チュートリアル：赤ラインを離した瞬間から約0.5秒後に開始。既存の120msの確定処理を含めて待ち時間を計算する。実測約0.49秒。別解・操作中・判定中・フォーカスと中断の既存条件は維持。
- リセット矢印：矢印単体の透過PNGを内蔵画像生成ツールで生成して差し替え。3ボタン共通で使用し、黄色のボタンでは濃紺へ着色。最大256ピクセルでインポートし、136×136のUI領域へ縦横比を保って表示。
- STAGE CLEAR!：文字だけ96〜104%に拡大・縮小するループを追加。片道0.65秒のSine補間。表示中は継続し、再開・中断・シーン遷移では停止して通常倍率へ戻す。Stage番号ボタンの操作を妨げない。
- タイトル背景：ロゴと混色イラストを背景透過の別素材に分離。空と雲を全画面のToonSkyGraphicだけで描画し、背景付きのRawImageは無効化してテクスチャ参照も解除。通常・縦長・タブレット比率で確認。
- 振動：ユーザーの指定により実機確認を後回し。既存処理とAndroid権限は変更していない。
