## 手とスワイプ

既存ゲームと同じ白い手袋・濃紺の輪郭・薄青い影を使っています。広告用に少し左へ傾けた手を内蔵 **image_gen** で生成し、全場面で同じ画像を使用しました。指先の接触リング、移動方向の矢印、薄い2段階の残像により、スワイプを示しています。完成場面では手を退場させて盤面を見せます。後半は手が白い穴を隠さない位置に置いています。

## 盤面とカメラ

盤面・文字・背景・パネルは、既存Toon Boldのコード由来の形状とLilita Oneフォントに合わせて描画しています。青空・雲、クリーム色の枠、濃紺の輪郭を継承しています。50×50は広告用の多色盤面です。

盤面A・Bとも、2500個の座標を持つデータから描画しました。全マスを一度ずつ通る経路と、隣接マス間だけの接続を検証済みです。盤面Aの最後の50マスは右端の列。盤面Bの最後の1マスは**上から26行目・左から26列目**で、05〜08はこの1マスだけが白です。接写では同じ盤面を拡大しています。

07は引き直しの方向を示す静止キーフレームです。動画では最後の赤い9マスを一度巻き戻し、穴の下のマスで上へ曲がるべきところを右へ進み、周囲の8マスを再着色して2499へ戻します。白い穴を増やさず、同じ1マスを見落とす演出にします。
